# Rust Player Tracker — Rust+ Connector

Расширение связывает официальный вход Rust+ от Facepunch с сайтом Rust Player Tracker.

## Установка в Chrome или Edge

1. Скачай папку `extension` из репозитория.
2. Открой `chrome://extensions` (в Edge — `edge://extensions`).
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение» и выбери папку `extension`.
5. Открой сайт Rust Player Tracker и обнови страницу.

## Использование

1. Сначала войди на сайте через Steam.
2. Открой вкладку Rust+ и нажми «Подключить через Facepunch».
3. В открывшейся вкладке войди на официальном сайте Facepunch через Steam.
4. После возврата на сайт нажми «Получить авторизацию из расширения», проверь совпадение SteamID и подтверди передачу.
5. Расширение удаляет ожидающий токен из своей временной сессии после чтения.

## Безопасность

- Расширение работает только с переходом авторизации Rust+ и страницей сайта.
- Оно не читает пароль Steam, cookies, историю браузера или содержимое других сайтов.
- Токен хранится только во временном `chrome.storage.session` до импорта.
- Перед отправкой на Worker сайт сверяет SteamID Rust+ с текущей Steam-сессией сайта.
- Токен является секретом: не показывай его на экране и не отправляй другим людям.

## Ограничение текущей версии

Facepunch возвращает из этого шага auth token и SteamID. Данные конкретной привязки игрового сервера (server ID / player token) приходят отдельным этапом после Pair with Server в игре через push-уведомление. Регистрация push-устройства и получение таких уведомлений на серверной стороне ещё не реализованы в этой версии. Поэтому успешный импорт авторизации сам по себе ещё не означает, что живая карта и команда уже подключены.
